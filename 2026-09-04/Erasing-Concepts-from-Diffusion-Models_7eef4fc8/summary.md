# 论文速读：Erasing-Concepts-from-Diffusion-Models

## 一句话总结
本文提出了 **Erased Stable Diffusion (ESD)**，一种仅凭概念名称的简短文本描述、无需额外训练数据，即可通过微调预训练扩散模型权重来永久性擦除特定视觉概念（如裸露内容、艺术家风格或物体类别）的方法。该方法利用冻结模型的负向引导（negative guidance）作为教师信号，使编辑后的模型从根本上降低生成目标概念的倾向，且效果不可被模型权重访问者轻易绕过。

## 研究问题与动机
- **核心问题**：大规模文本到图像扩散模型会学习并生成 undesirable concepts（如色情内容、受版权保护的艺术家风格、特定物体），而现有解决方案存在明显缺陷。
- **现有方法不足**：
    1. **训练集过滤/重新训练**（如 SD 2.0）：成本极高（消耗 150,000 GPU 小时），且难以建立数据变更与能力下降之间的因果关系；过度审查还可能意外损害模型在其他主题上的生成质量。
    2. **推理时后处理/引导**（如 NSFW 过滤器、Safe Latent Diffusion）：效率高、易部署，但一旦被开源模型（如 Stable Diffusion）的权重和代码公开，极易被用户绕过或禁用。
    3. **对抗性扰码/图像Cloaking**：保护的是内容创作者在上传前的图像，而非从已训练好的模型中移除已被学习的概念。
- **驱动动机**：需要在不重新训练、不依赖额外数据的前提下，实现一种快速、有效且难以绕过的概念擦除手段，以应对安全（NSFW）和版权/风格模仿（艺术家风格）等关切。

## 核心贡献（创新点）
1. **提出了仅凭文本描述的概念擦除方法 ESD**：与需要大量筛选数据或重训整个模型的方法不同，ESD 仅需目标概念的简短文本名称（如"nudity"、"Van Gogh"）即可指导微调，无需收集负面示例或进行昂贵重新训练。
2. **利用冻结模型的负向引导生成伪训练信号**：本质区别在于将推理时的 classifier-free guidance 公式（`ε_uncond + α(ε_cond - ε_uncond)`）在 η=1 时取反，构造出一个“负向引导噪声预测”作为目标，用于微调新参数 θ，从而让模型从内部学会远离该概念，而非仅在推理时临时规避。
3. **区分条件擦除（ESD-x）与非条件擦除（ESD-u）的参数子集选择策略**：针对性地微调 cross-attention 参数可实现与提示词强绑定的风格/概念移除（如仅当提示词包含"Van Gogh"时才移除其风格）；微调非 cross-attention（unconditional）参数可实现全局、不依赖提示词的擦除（如彻底移除裸露内容）。这是本文对“擦除粒度”控制的关键创新。
4. **系统性 benchmark 涵盖安全内容、艺术风格、物体类别及记忆图像的多场景验证**：在 I2P 基准上达到与 SLD 相当的裸露内容移除效果（SD 1.4 产生 796 张违规图，ESD-u 降至 134 张）；在 COCO 30k 上 FID（13.68）优于 SLD 和原版 SD；用户研究表明其风格擦除效果显著且对未目标风格干扰最小；此外还首次展示了单个记忆图像（如《星月夜》）的精细擦除能力。
5. **揭示并量化了擦除强度参数 η 在有效性 vs. 干扰之间的权衡关系**：通过系统 ablation 表明，减小 η 可缓解对无关概念的干扰并提升图像保真度，为实际应用提供了可调参数依据。

## 方法详解
- **整体流程**：给定预训练 Stable Diffusion 模型 θ*（含 U-Net、文本编码器 T、解码器 D）和目标擦除概念 c 的文本描述，通过以下过程微调一套新参数 θ：
    1. **采样部分去噪潜变量**：使用当前参数 θ 对概念 c 进行条件扩散采样，得到部分去噪的潜变量 x_t。
    2. **获取冻结模型的噪声预测**：在冻结参数 θ* 下，对同一 x_t 分别进行条件（输入提示 c）和无条件（空提示）噪声预测，得到 ε_θ*(x_t, c, t) 和 ε_θ*(x_t, t)。
    3. **构造负向引导目标**：计算差异向量 Δε = ε_θ*(x_t, c, t) - ε_θ*(x_t, t)，并用缩放因子 η 控制强度，得到目标噪声预测：
       `ε_target = ε_θ*(x_t, t) - η * [ε_θ*(x_t, c, t) - ε_θ*(x_t, t)]`
    4. **微调损失**：最小化新模型预测噪声 ε_θ(x_t, c, t) 与 ε_target 之间的 MSE 损失：
       `L = || ε_θ(x_t, c, t) - (ε_θ*(x_t, t) - η[ε_θ*(x_t, c, t) - ε_θ*(x_t, t)]) ||²`
       这等价于让 θ 学会近似一个“负向引导”的分数函数，从而在生成分布 P_θ(x) ∝ P_θ*(x) / P_θ*(c|x)^η 中降低 c 相关内容的概率。
- **参数选择策略**：
    - **ESD-x（条件擦除）**：仅微调 U-Net 中的 cross-attention 层。适用于需与文本提示绑定的擦除（如特定艺术家风格），移除效果仅在提示词包含该概念时生效。
    - **ESD-u（非条件擦除）**：仅微调 U-Net 中的非 cross-attention 层（如 self-attention、时间嵌入网络等）。适用于全局性、不依赖提示词的擦除（如裸露内容），即使提示词未提及该概念也会生效。
- **超参数**：η（负向引导强度，默认 1；文中测试了 η=1, 3, 10）；优化器 Adam；学习率 1e-5；批量大小 1；训练步数 1000 步。

## 实验与结果
- **数据集与评估基准**：
    - **艺术风格擦除**：选取 5 位现代艺术家/系列（Kelly McKernan, Thomas Kinkade, Tyler Edlin, Kilian Eng, Ajin: Demi-Human），为每位艺术家收集 40 幅真实作品及 40 个风格提示词（共 1000 张生成图像），并结合相似风格艺术家的作品进行用户研究。
    - **裸露内容擦除**：使用 I2P（4,703 个不当提示词）基准生成图像，通过 Nudenet 检测器分类统计暴露身体部位图像比例；使用 COCO 30k 评估图像保真度（FID-30k）与条件特异性（CLIP score）。
    - **物体类别擦除**：基于 Imagenette 子集（10 个易识别类别），对每个类别训练一个 ESD-u 模型，用 ResNet-50 分类器评估擦除前后目标类别及未目标类别的分类准确率。
    - **记忆图像擦除**：以梵高《星月夜》为例，使用真实图像通过前向扩散过程添加噪声得到部分去噪版本进行训练。
- **主要结果**：
    - **艺术风格**：用户研究显示，ESD-x 将生成图像与目标艺术家风格的相似度评分从 SD 的 3.21 降至 1.12（SLD 为 2.00，SD-Neg-Prompt 为 2.22），且对未目标风格干扰最小（用户认为其更可能是“真实艺术作品”）。
    - **裸露内容**：在 I2P 基准上，ESD-u（η=1）将 SD 1.4 模型生成的裸露图像数量从 796 张大幅降至 134 张，优于 Safe Latent Diffusion（SLD）和经过严格 NSFW 过滤重新训练的 SD 2.0。
    - **图像保真度**：在 COCO 30k 上，ESD-u 的 FID-30k 为 13.68，优于 SD（14.50）和 SLD-Medium1（16.90）、SLD-Max（18.76）；CLIP score 与 SD 基本持平（0.1585 vs 0.1592），表明条件生成能力未受损。
    - **物体类别**：平均分类准确率从 SD 的 78.2% 降至 ESD-u 的 12.6%；但未目标类别的平均准确率从 78.2% 降至 63.2%，显示一定干扰；个别类别（如"church"，从 73.8% 仅降至 54.2%）难以完全擦除。
    - **记忆图像**：擦除《星月夜》后，梵高风格及其他记忆作品受影响极小（LPIPS 变化低），实现了精细擦除。
- **最强结果与提升幅度**：在裸露内容移除任务上，ESD-u 相比原始 SD 1.4 将违规图像数量降低了约 **83.2%**（从 796 张降至 134 张），性能达到甚至略超 SLD 和经过昂贵重新训练的 SD 2.0，同时保持了更高的图像保真度（更低 FID）。

## 相关工作脉络
1. **Safe Latent Diffusion (SLD)**：最先进的推理时负向引导方法，通过在采样过程中动态调整分数估计来规避不安全概念。ESD 与之定位不同：SLD 是推理时临时干预，可被绕过；ESD 是修改模型权重，实现永久性擦除。
2. **Stable Diffusion 2.0 (SD-V2.0)**：通过从 LAION-5B 中移除不当内容并重新训练模型来过滤 NSFW。ESD 避免了高达 150,000 GPU 小时的重新训练成本，且针对特定概念进行精准移除，而非全局数据清洗可能带来的质量损失。
3. **Classifier-free Guidance (Ho & Salimans, 2022)**：ESD 直接借鉴了其条件与无条件分数预测的差值结构，但将其从推理时的生成控制工具转化为微调过程的训练目标，实现了“用模型自身知识教导自己远离某概念”。
4. **图像 Cloaking (如 Glaze)**：通过向艺术家上传的图像添加对抗性扰动，阻止模型学习其风格。ESD 解决的是相反问题：模型已经学会了该风格，如何将其从模型权重中移除，且无需内容创作者事先采取防护措施。
5. **Machine Unlearning**：传统机器遗忘方法旨在模拟移除已知训练数据点的影响。ESD 针对的是高层视觉概念（如“裸露”、“某艺术家风格”），这些概念可能由海量未知训练样本共同编码，无法对应到具体数据点。
6. **模型编辑方法（如 Rewriting a Deep Generative Model）**：在 GAN 中使用少量样本或提示词编辑模型行为。ESD 专注于扩散模型，且只需文本描述无需额外图像，更轻量级。

## 局限性与未来方向
- **擦除完整性与干扰的权衡**：对于大型概念（如整个物体类别或部分艺术风格），完全擦除往往伴随对未目标概念的干扰（如移除“法国号”会影响其他类别图像质量）。η 减小可缓解干扰但降低擦除效果。
- **部分类别擦除不彻底**：某些物体类别（如"church"）只能擦除其显著属性（如十字架、肋骨），而无法完全移除概念本身，提示擦除效果可能存在上限。
- **多概念同时擦除的累积干扰**：虽然单个记忆图像的擦除干扰很小，但同时擦除多个记忆图像开始影响其他无关的记忆作品，尽管对非艺术生成影响较小。
- **未来方向**：探索更精细的参数子集选择以进一步隔离擦除效果；研究如何在保证擦除强度的同时最小化对未目标概念的干扰；将方法扩展到视频生成或其他多模态生成模型；自动化检测并擦除潜在版权风险或有害概念。

## 研究启发与可借鉴点
1. **将推理时引导技术转化为训练目标**：classifier-free guidance 的差值形式被创造性地用作监督信号，这种“自蒸馏”式的无数据微调策略可推广至其他需要特定行为修正的生成模型。
2. **参数子集的选择作为可控性杠杆**：明确区分 cross-attention（与文本提示绑定）和非 cross-attention（全局特征）参数的不同作用，为模型编辑提供了可解释的控制维度，启发后续研究针对不同概念类型设计细粒度的编辑策略。
3. **用户研究作为主观效果评估的黄金标准**：在艺术风格擦除中引入与真人作品对比的用户研究，量化了“感知相似度”，弥补了纯自动指标（如 FID、CLIP）在评估主观艺术风格方面的不足，为后续研究提供了评估范式。
4. **记忆图像擦除的可行性验证**：证明基于少数真实图像（而非模型生成样本）可进行精细擦除，且对未目标概念干扰极小，这为处理具体版权侵权案例（如移除某幅特定画作）提供了技术路径。
5. **超参数 η 的系统性 ablation 揭示 trade-off**：对 η 值的实验清晰展示了擦除有效性、图像保真度和跨概念干扰三者间的权衡曲线，这种定量分析为实际应用中的参数选择提供了直接指导。

## 关键术语表
- **Erased Stable Diffusion (ESD)**：本文提出的方法框架，通过微调预训练扩散模型权重来擦除特定视觉概念。
- **Negative Guidance**：在 classifier-free guidance 基础上取反差值（ε_uncond - (ε_cond - ε_uncond)），作为训练目标使模型输出远离条件提示所描述的概念。
- **ESD-x / ESD-u**：两种参数微调变体；ESD-x 仅微调 cross-attention 层，实现与提示词绑定的条件擦除；ESD-u 仅微调非 cross-attention 层，实现全局无条件擦除。
- **I2P (Inappropriate Image Prompts)**：包含 4,703 个旨在生成不当内容的提示词基准，用于评估裸露内容移除方法的有效性。
- **Nudenet**：用于检测图像中暴露身体部位的深度学习检测器，在实验中用于量化生成图像中的违规内容比例。
- **Imagenette**：ImageNet 的一个子集，包含 10 个易于识别的类别，用于评估物体类别擦除后的分类准确率变化。
- **LPIPS (Learned Perceptual Image Patch Similarity)**：用于衡量图像间感知差异的指标，文中用于量化擦除操作对记忆作品和其他生成图像的影响程度。
- **Classifier-free Guidance**：扩散模型中同时使用条件和无条件预测进行推理控制的经典技术，ESD 的核心灵感来源。

## 可复现要素
- **数据集**：
    - 艺术风格评估：从 Google Image Search 收集 5 位艺术家的各 40 幅作品；使用自定义提示词列表生成图像；包含相似艺术家作品作为对照。
    - 裸露内容评估：I2P 基准（4,703 提示词）；COCO 30k（评估保真度）。
    - 物体擦除评估：Imagenette 子集（10 个类别）。
- **代码与权重**：论文声明代码、数据集和微调模型权重均在项目网站 `https://erasing.baulab.info` 及 GitHub 仓库 `https://github.com/rohitgandikota/erasing` 开源。
- **关键超参数**：优化器 Adam；学习率 1e-5；批量大小 1；训练步数 1000 步；η（负向引导强度）默认 1，另测试 η=3, 10；推理时 guidance scale α=7.5（用于 FID/CLIP 评估）。
- **基础模型**：Stable Diffusion v1.4（除非另有说明）。
