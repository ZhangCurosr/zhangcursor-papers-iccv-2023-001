# 论文速读：Point-Query-Quadtree-for-Crowd-Counting-Localization-and-More

## 一句话总结
本文提出将人群计数形式化为**可分解的点查询过程**，设计了**Point quEry Transformer (PET)**，通过点查询四叉树自适应分裂与渐进矩形窗口注意力，首次实现单个模型在完全监督计数/定位、部分标注学习、点标注精炼等多个任务上均达到SOTA。

## 研究问题与动机
1. **现有密度图方法缺乏实例级理解**：主流方法通过密度图积分获取计数值，无法提供人头位置等细粒度信息，阻碍高层人群分析。
2. **检测框方法在拥挤场景可靠性不足**：基于边界框的计数本质是检测问题，但伪GT框（由弱点监督生成）在密集区域误差大，影响训练与预测。
3. **点预测方法依赖启发式后处理**：直接输出点坐标的方法通常需要后处理区分个体，拥挤场景易失败。
4. **不同任务需定制化设计**：已有方法通常针对单一任务或学习范式（如全监督无法适配半监督），缺乏通用性。

## 核心贡献（创新点）
1. **形式化人群计数为可分解点查询过程**：允许任意点作为输入并推理其是否为人头及位置，输入点数和位置均可控，天然适配多种人群相关任务。
2. **设计点查询四叉树（Point-Query Quadtree）实现自适应分割**：稀疏查询点可在密集区域动态分裂为更密集的点，避免固定查询数的欠估计或计算浪费；与DETR类固定query方法本质不同。
3. **提出渐进矩形窗口注意力机制**：基于透视先验，编码器/解码器均在水平矩形窗口内计算注意力，实现线性复杂度且适配高分辨率图像；与全局注意力/可变形注意力相比更高效且对分辨率变化鲁棒。
4. **首个统一多任务的人群计数框架**：单模型PET在完全监督计数/定位、部分标注学习、点标注精炼三个不同范式下均取得SOTA，验证了点查询范式的通用性。

## 方法详解
**整体架构**：CNN骨干（VGG16）→ Transformer编码器（渐进矩形窗口自注意力）→ 点查询四叉树构建 → Transformer解码器（矩形窗口交叉/自注意力）→ 预测头。

**点查询四叉树**：
- 初始层（Level 0）：以步长K=8均匀采样稀疏查询点。
- 分裂准则：通过quadtree splitter（平均池化+1×1卷积+Sigmoid）输出分裂图$M_s$，概率>0.5的区域判为密集区并进行分裂。
- 分裂后每点生成4个新点（Level 1），最大深度L=2（实际L=1通常足够）。
- 查询点表示：对CNN特征$\mathcal{F}$双线性插值到原图尺寸，在$(x,y)$处采样特征向量，与固定空间位置编码相加。

**渐进矩形窗口注意力**：
- 编码器：前几层在大矩形窗口（尺寸$s_e \times r_e s_e$，$s_e=16, r_e=2$）计算自注意力，后续层窗口缩小一半，逐步聚焦局部上下文。
- 解码器：稀疏查询点在较大窗口（$\frac{1}{2}s_e \times \frac{1}{2}r_e s_e$）计算自注意力，密集查询点在更小窗口（$\frac{1}{4}s_e \times \frac{1}{4}r_e s_e$）计算；交叉注意力也在矩形窗口内完成。

**预测头**：MLP（ReLU激活）输出分类概率$c_i \in [0,1]$和归一化偏移$(\Delta x_i, \Delta y_i)$，最终位置为$(x_i+\Delta x_i, y_i+\Delta y_i)$。

**损失函数**：
- 点查询损失（二分匹配）：$\ell_{pq} = \frac{1}{N}\sum_{i=1}^{N}\ell_{cls}(c_i, c_i^*) + \lambda_1\frac{1}{M}\sum_{i=1}^{M}\ell_{loc}(\mathbf{p}_{\sigma(i)}, \mathbf{y}_i)$，其中$\ell_{cls}$为交叉熵，$\ell_{loc}$为smooth $\ell_1$。
- 分裂图监督：$\ell_{split} = \mathbb{1}(\text{dense})(1-\max(M_s)) + \min(M_s)$，约束四叉树区分稠密/稀疏区域。
- 总损失：$\ell_{total} = \ell_{pq} + \lambda_2 \ell_{split}$，$\lambda_1=5.0, \lambda_2=0.1$。
- **双路监督**：按密度将mini-batch分为稀疏/密集两组分别计算损失后相加，防止稀疏样本稀释梯度。

## 实验与结果
**数据集**：ShanghaiTech PartA/PartB、UCF-QNRF、JHU-Crowd++、NWPU-Crowd；评估指标为MAE和MSE。

**主要结果**：
- **ShanghaiTech PartA**：MAE **49.34**（SOTA，较次优P2PNet的52.74降低约3.4）；PartB：MAE 6.19。
- **UCF-QNRF**：MAE **79.53**（SOTA）。
- **JHU-Crowd++**：MAE **58.5**（SOTA）。
- **NWPU-Crowd**：MAE **74.4**（SOTA）；定位F1-m达0.742，显著优于CLTR等。

**部分标注学习**（10%标注比例）：SH PartA MAE **60.36**，大幅优于Xu et al. [39]的72.79，甚至接近全监督方法。

**点标注精炼**：将原始标注输入PET作为查询，可校正噪声点至人头中心；用精炼后标注重训练后MAE从49.34降至**48.52**。

**消融关键数字**：
- 四叉树贡献：SH PartA提升约**4 MAE**，UCF-QNRF提升约**11 MAE**。
- 渐进矩形窗注意力：完整配置（49.34）vs 无渐进（52.00）vs 单侧矩形窗（51.93/52.48）。
- 效率：参数量20.9M（最少），推理时间0.097s（与P2PNet 0.074s相近）。

## 相关工作脉络
1. **密度图方法**（CSRNet、CAN、BL+、ASNet、DM-Count、NoisyCC等）：以密度图为监督目标，无法输出实例级位置；PET提供逐点预测，弥补此缺陷。
2. **基于检测框的方法**（Faster R-CNN、TinyFaces、RAZNet、GL等）：将计数视为检测任务，依赖伪GT框易受拥挤干扰；PET直接点预测，规避框估计误差传播。
3. **点预测方法**（P2PNet、D2CNet、CLTR）：直接输出点坐标但通常需后处理；PET通过点查询机制端到端推理，无需额外后处理且支持自适应查询数。
4. **Transformer计数方法**（MAN、CLTR等）：主要聚焦增强骨干特征提取；PET从任务形式化出发，提出可分解查询范式，视角更底层。
5. **部分标注学习**（Xu et al. [39]）：需设计一致性约束；PET利用点查询泛化能力，两步简单训练即超越，证明范式优势。
6. **噪声标注学习**（NoisyCC等）：PET展示了对标注质量的敏感性与校正能力，为后续标注精炼研究提供新思路。

## 局限性与未来方向
1. **大目标漏检风险**：矩形窗口尺寸有限，当人头较大时可能覆盖不足导致漏检。
2. **点查询表示有待改进**：当前仅使用CNN特征+固定位置编码，语义/几何信息融合可进一步优化。
3. **未验证极端密度场景**：虽在UCF-QNRF/JHU-Crowd++表现良好，但极高密度（如>5000人/图）下的稳健性需进一步检验。
4. **未来方向**：将点查询框架扩展至其他密集预测任务（如密集分割、关键点检测）；改进查询点表示以编码更多上下文/几何信息。

## 研究启发与可借鉴点
1. **可分解查询范式**：将计数/检测任务重构为"查询-推理"过程，为多任务统一建模提供新思路；可迁移至其他 Instance-level 预测任务。
2. **数据驱动的自适应结构**：四叉树分裂机制实现了场景自适应的查询密度调节，启发在其他需要动态计算量的任务（如可变长度序列建模）中应用类似思想。
3. **透视先验引导的窗口设计**：水平矩形窗口比正方形窗口更适合人群图像，提示在设计Vision Transformer局部注意力时应结合任务特有的几何先验。
4. **双路监督策略**：按密度分层计算损失再求和，防止稀疏样本梯度稀释；可推广至其他样本间差异大的场景（如长尾识别、多尺度检测）。
5. **标注精炼作为附加价值**：PET可作为标注后处理工具，无需额外训练即可校正噪声GT；在数据标注成本高或噪声严重的领域具有实用价值。

## 关键术语表
- **Point-Query Quadtree**：一种可分解的数据结构，查询点可根据区域密集程度自适应分裂为四个子点，实现稀疏/密集场景的动态处理。
- **Progressive Rectangle Window Attention**：编码器/解码器中逐层缩小矩形窗口的注意力机制，基于人群图像的透视先验设计，兼顾效率与性能。
- **Bipartite Matching Loss**：匈牙利算法匹配预测点与GT点的二分匹配损失，用于处理可变数量预测的目标检测类任务。
- **Partial Annotation Learning**：仅对图像部分区域提供标注的学习范式，旨在降低标注成本并利用多场景数据。
- **Dual Supervision**：将batch按密度分为稀疏/密集两组分别计算损失后叠加的训练策略，防止低密度样本梯度被稀释。
- **Point Query Representation**：将像素坐标处的CNN特征与固定空间位置编码相加，形成同时含语义和位置信息的查询向量。
- **Split Map**：四叉树分裂网络输出的概率图，表征图像各区域是否需要分裂，阈值0.5判定为密集/稀疏。
- **Density Map**：传统人群计数方法的监督目标，每个像素值表示该位置的人群密度，积分后得计数。

- **数据集**：ShanghaiTech PartA/PartB、UCF-QNRF、JHU-Crowd++、NWPU-Crowd（均为公开数据集）。
- **代码**：已开源，GitHub: https://github.com/cxliu0/PET。
- **权重**：论文未明确说明权重开源情况，代码仓库中可能包含。
- **关键超参**：骨干网络VGG16；查询点初始步长K=8；四叉树最大深度L=2（实际有效深度1）；Transformer编码器4层、解码器2层；窗口参数$s_e=16, r_e=2$；损失权重$\lambda_1=5.0, \lambda_2=0.1$；学习率骨干$10^{-5}$、Transformer$10^{-4}$；权重衰减$5\times10^{-4}$；优化器Adam。
