# 论文速读：Deep-Geometrized-Cartoon-Line-Inbetweening

## 一句话总结
本文提出 **AnimeInbet**，将卡通线稿栅格图像几何化为向量图（端点 + 连接关系），把中间帧生成任务重新表述为**图融合 + 顶点重定位**问题，并引入配套数据集 **MixamoLine240**，在定量与定性上全面超越现有光栅帧插值方法，尤其在大运动场景下优势显著。

## 研究问题与动机
- **线稿逐帧绘制耗时昂贵**：2D 动画中角色线稿仍需手工逐帧绘制，中间帧（inbetweening）是人力密集型工序，自动化潜力巨大。
- **稀疏结构使像素级匹配失效**：线稿仅约 3% 黑色像素，纹理几乎缺失，现有帧插值的像素对应搜索空间极大，容易产生错误匹配。
- **Warp-blend 破坏线条细节**：传统方法的仿射/光流扭曲与混合会模糊线条与背景之间的锐利边界，生成结果出现模糊或断裂，无法用于实际制作。
- **现有方法缺乏专门设计**：虽有少量针对 2D 动画的帧插值尝试（如 EISAI、AnimeRun），但均以光栅图像为基础，未解决线稿的"极稀疏 + 拓扑精确"需求。

## 核心贡献（创新点）
1. **将线稿内插从光栅域转移到几何图域**：把输入转化为端点坐标与邻接矩阵表示的向量图，以顶点重定位替代像素扭曲，从根本上规避模糊 artifacts。
2. **多源顶点几何嵌入（Vertex Geometric Embedding）**：联合编码图像上下文（2D CNN）、位置（1D CNN）与拓扑（谱嵌入 +1D CNN）三维信息，使稀疏线稿的每个端点具备可区分性；与常规特征提取的本质区别在于显式保留图结构先验。
3. **基于可微最优传输的顶点匹配 Transformer**：交替自注意力/交叉注意力聚合后，用 OT 正则化提升双向一致性，再以双方向 argmax + 阈值筛选对应关系；区别于通用点对匹配的在于同时处理拓扑图约束与大运动遮挡。
4. **基于注意力的未匹配顶点位移传播机制**：用特征自注意力加权聚合已知匹配顶点的位移向量，为 occluded/unmatched 顶点预测合理重定位，与单纯插值或光流传播的本质区别是"拓扑邻域感知"的位移扩散。
5. **公开首个几何化线稿数据集 MixamoLine240**：利用 Blender Cel-shading 从 3D 网格渲染 240 条线稿序列，以 3D 顶点索引提供精确的图级几何化标注与顶点对应 GT，填补了该领域数据空白。

## 方法详解
**整体框架（Figure 5）**：给定帧对 $(I_0, I_1)$ 及其向量图 $G_0=\{V_0, T_0\}, G_1=\{V_1, T_1\}$，生成中间图 $G_t$，$t \in (0,1)$。

1. **顶点几何嵌入（§4.1）**：
   $$F_0 = \mathcal{E}_I(I_0)[V_0] + \mathcal{E}_P(V_0) + \mathcal{E}_T(S(T_0))$$
   - $\mathcal{E}_I$：3 层 2D CNN，提取图像上下文特征后按顶点坐标采样；
   - $\mathcal{E}_P$：1D CNN，将 $(x,y)$ 映射为 C 维位置特征；
   - $\mathcal{E}_T$：先对邻接矩阵做拉普拉斯谱嵌入（S），再经 1D CNN 压缩至 64 维。
   最终特征维度 $C=128$。

2. **顶点匹配 Transformer（§4.2）**：
   - 堆叠 N 层自注意力 + 交叉注意力交替层（公式 2、3），使每顶点聚合两图内全局相互信息；
   - 相关矩阵 $\mathcal{P} = \hat{F}_0 \hat{F}_1^T / \sqrt{C}$，经可微最优传输 $\hat{\mathcal{P}} = OT(\mathcal{P})$ 增强双向一致性；
   - 双向 argmax 得到 $\mathcal{M}_{0→1}, \mathcal{M}_{1→0}$，取交集且 $\hat{\mathcal{P}}_{i,j} > \theta$（$\theta=0.2$）作为最终匹配集 $\hat{\mathcal{M}}$，否则标记为遮挡。

3. **位移传播重定位（§4.3）**：
   - 对已匹配顶点：直接线性插值 $V_t = (1-t)V_0[i] + t V_1[j]$；
   - 对未匹配顶点：用自注意力加权聚合已知匹配位移
     $$r_{0→1} = \text{softmax}\!\left(\frac{\hat{F}_0 \hat{F}_0^T}{\sqrt{C}}\right)(\text{softmax}(\hat{\mathcal{P}})V_1 - V_0)$$
     最终 $r_0[i]$ 为直接差值或传播值（公式 7）。

4. **可见性预测与图融合（§4.4）**：
   - 3 层 MLP 预测 $m_0 = \text{MLP}(\hat{F}_0), m_1 = \text{MLP}(\hat{F}_1)$；
   - 按规则（公式 8）合并可见顶点的重定位坐标，合并邻接关系保持两端点均可见的原始边。

5. **损失函数（§4.5）**：
   - $\mathcal{L}_c = -\frac{1}{|\mathcal{M}^{GT}|}\sum_{(i,j)\in\mathcal{M}^{GT}} \log \hat{\mathcal{P}}_{i,j}$（匹配置信度最大化）；
   - $\mathcal{L}_r$：对传播位移做 L1 回归（公式 10）；
   - $\mathcal{L}_m$：带偏置权重 $w=0.2$ 的 BCE，监督遮挡可见性（公式 10）；
   - **伪标签生成**：因大帧间隙遮挡顶点无 GT 位移，从相邻帧（gap=0）开始逐帧回溯（公式 11），利用高匹配率累积 pseudo shift；可见性 GT 通过将回溯位移投影到中间帧并膨胀 $3\times3$ 核判定（公式 12）。

6. **训练策略**：前 50 个 epoch 仅使用 $\mathcal{L}_c$，后 20 个 epoch 启用全损失；Adam lr=$10^{-4}$，单卡 V100 约 5 天。

## 实验与结果
- **数据集**：MixamoLine240，100 条训练序列（19,930 帧）、44 条验证、140 条测试（18,230 帧），分辨率统一 $720\times720$，fps=60。
- **评估指标**：Chamfer Distance（CD，越低越好），将预测二值化（阈值=0.99×max）后计算。
- **基线方法**：VFIformer、RIFE、EISAI、FILM（均在训练集上微调 5 epoch，lr=$10^{-6}$）。
- **定量结果（Table 2，Test Set）**：
  | 方法 | gap=1 | gap=5 | gap=9 | Avg. |
  |---|---|---|---|---|
  | FILM（最佳基线） | 3.50 | 17.94 | 33.51 | 18.31 |
  | **AnimeInbet** | **2.80** | **12.69** | **23.21** | **12.90** |
  - 平均 CD 提升约 **29.5%**（18.31→12.90）；大帧间隙优势更显著（gap=9 提升 31%）。
  - 使用 VirtualSketcher 向量化输入（AnimeInbet-VS）平均 CD=13.51，略降但仍大幅领先基线。
- **用户研究（Figure 9）**：36 位参与者双盲对比，AnimeInbet 胜率超过 **92%**；gap=5 和 gap=9 时接近 **100%**，说明大运动下优势更突出。
- **消融**：去除位置嵌入 CD 升 0.74，去除拓扑嵌入升 0.43；去除位移传播 CD 从 11.12 剧增至 23.62（+112%），去除可见性掩码升至 12.81（+15%）。

## 相关工作脉络
- **帧插值主流方法（RIFE、FILM、VFIformer 等）**：以光栅像素为操作对象，通过光流预测 + warp-blend 合成中间帧；本文将其作为基线对比，指出其在稀疏线稿上的根本性缺陷（像素级匹配歧义 + warp 模糊线条）。
- **EISAI（Chen & Zwicker, ECCV 2022）**：专门为 2D 动画设计的像素级插值，嵌入光流轮廓聚合器；本文方法与之本质区别在于操作对象从像素提升到**顶点**，彻底避免 blend 导致的线条模糊。
- **AnimeRun（Siyao et al., NeurIPS 2022）**：从开源 3D 电影提取 2D 动画视图中对应的 2D 关键点；本文扩展为该思路的 **线稿序列几何化标注**，并提供完整的顶点对应与可见性 GT。
- **Creative Flow+（Shugrina et al., CVPR 2019）**：提供动画关键帧对对应点，但仅给光栅图像而非几何化图结构，无法直接用于本文的图融合任务。
- **线稿矢量化方法（VirtualSketcher、End-to-end vectorization 等）**：作为前置模块可接入本框架（AnimeInbet-VS），但本文表明 GT 向量化质量直接影响最终插值效果（587 vs 1351 平均顶点数差异明显）。
- **规则类笔划内插方法（Dilight 等）**：依赖严格条件限制，缺乏泛化性；本文首次提出端到端深度学习线稿内插方法。

## 局限性与未来方向
- **依赖高质量向量化输入**：现用 GT 向量来自 3D 渲染，实际场景中若由 VirtualSketcher 等自动矢量化，顶点数量不足（587 vs 1351）会导致细节丢失（Figure 10）。
- **顶点数差异较大的跨帧匹配挑战**：训练集平均 1256 顶点、测试集 1512 顶点，复杂角色（如"Maw"）顶点更多，泛化到显著拓扑变化的场景仍有压力。
- **训练数据均为 Blender Cel-shading 风格**：合成数据的线条风格与真实手绘线稿存在域差异，零样本迁移能力有待验证。
- **当前仅支持固定 $t=0.5$ 中心帧生成**（虽公式支持任意 $t$，但实验未充分探索）；多帧连续插值的时序一致性未系统评估。
- **未讨论实时推理速度**：与工业级动画生产工具链（如 Toon Boom）的集成效率待评估。

## 研究启发与可借鉴点
1. **"几何化抽象 + 图融合"范式可用于其他稀疏结构任务**：如骨骼动画中间帧生成、点云变形插值、CAD 草图补间等，将操作对象从像素转移到结构化实体是规避纹理缺失问题的通用思路。
2. **多源特征融合嵌入设计**：图像上下文 + 位置 + 拓扑三源相加的策略（公式 1）兼顾局部感知与全局结构，可直接迁移到点云配准、图匹配等下游任务。
3. **可微最优传输用于双向一致性匹配**：OT 正则化提升对应一致性的做法（Superglue 思路）在稀疏特征场景下尤为有效，值得在细粒度视觉对应任务中复用。
4. **回溯伪标签生成策略**：从高匹配率相邻帧逐帧传播位移以构建遮挡顶点伪 GT，是一种巧妙的弱监督策略，可用于其他大位移运动的自监督训练设计。
5. **数据集构建思路**：利用 3D 模型顶点索引提供"精确锚点"来生成对应关系 GT，为其他 3D→2D 对应学习任务提供了可复用的数据合成范式。

## 关键术语表
- **Inbetweening（中间帧生成）**：在两个关键帧之间自动生成过渡帧的动画制作过程。
- **Geometrized line drawing（几何化线稿）**：将线稿图像表示为由端点坐标（V）和邻接矩阵（T）构成的向量图。
- **Vertex Geometric Embedding（顶点几何嵌入）**：融合图像上下文、坐标位置与图拓扑谱特征的顶点表示方法。
- **Optimal Transport（OT，最优传输）**：用于正则化匹配矩阵、提升双向一致性的一种可微分距离度量。
- **Repositioning Propagation（重定位传播）**：通过注意力加权将已知匹配顶点的位移扩散至未匹配顶点的机制。
- **Visibility Mask（可见性掩码）**：预测哪些顶点/边在中间帧中被遮挡而应被删除的二值输出。
- **Chamfer Distance（CD）**：衡量两组点集之间相互最近距离的平均值，用于评估线稿插值质量。
- **Cel-shading**：计算机图形学中模拟手绘风格的渲染技术，本文用于从 3D 模型生成线稿序列。

## 可复现要素
- **数据集**：MixamoLine240，代码与数据均在 [https://github.com/lisiyao21/AnimeInbet](https://github.com/lisiyao21/AnimeInbet) 开源（论文声明）。
- **代码**：已开源，包含训练与推理脚本。
- **关键超参**：特征维度 $C=128$，阈值 $\theta=0.2$，$\mathcal{E}_I$ 为 3 层 2D CNN，$\mathcal{E}_P/\mathcal{E}_T$ 为 kernel size=1 的 1D CNN，谱嵌入维度 64；lr=$10^{-4}$，前 50 epoch 只用 $\mathcal{L}_c$，后 20 epoch 加全损失；BCE 偏置权重 $w=0.2$；mini-batch 经梯度累积等效为 8；单卡 V100 约 5 天。
- **推理设置**：$t=0.5$， cv2.line 渲染线宽 2 像素。
- **Vectorization 工具**：基线测试中使用 VirtualSketcher（[15]）进行输入矢量化；论文未提及自动矢量化模块本身，需另选工具。
